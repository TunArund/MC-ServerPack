# 每行一个 JVM 参数；空行和以 # 开头的注释会被 Runtime 忽略。
# 默认匹配 config.yml 的 8g 容器上限，为非堆内存保留约 2G。
# 修改 mem-limit 后请同步调整 Xmx；不要将 Xmx 设为整台主机的全部内存。
-Xms2G
-Xmx6G

# Java 17/21 默认已使用 G1；显式写出以便 Java 8 也使用相同收集器。
-XX:+UseG1GC
# 200ms 是 G1 的软暂停目标，不是强制上限。
-XX:MaxGCPauseMillis=200
-XX:+ParallelRefProcEnabled
-XX:+DisableExplicitGC
-XX:+PerfDisableSharedMem
